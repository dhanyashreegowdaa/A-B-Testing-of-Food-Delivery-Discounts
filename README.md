## 📌 Project Overview

This project demonstrates **A/B Testing** using a simple food delivery scenario. The objective is to determine whether offering a **10% discount** or a **20% discount** results in a significant difference in customer ordering behavior.

The project uses a simulated dataset of **100 customers**, divided into two groups:

* **Group A:** 10% discount
* **Group B:** 20% discount

A statistical test is then performed to determine whether the difference in order rates is statistically significant.

---

## 🎯 Objectives

* Compare customer order rates for two different discounts.
* Calculate the order/response rate for each group.
* Form
